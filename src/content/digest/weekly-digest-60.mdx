## 🧪 HTML и веб-платформа

### Современный HTML берет на себя задачи, для которых раньше требовался JavaScript

Manuel Matuzović обновил свой [шаблон HTML-документа для 2026 года](https://www.matuzo.at/blog/2026/html-boilerplate) и подробно объяснил назначение элементов, которые использует в `<head>`. Это не заготовка для бездумного копирования, а удобная проверка базовых настроек страницы: кодировки, viewport, метаданных и других деталей, о которых легко забыть.

Chris Burnell дополняет тему восемью примерами того, [что современный HTML уже умеет без JavaScript](https://chrisburnell.com/html-can-do-that/). Среди них `popover`, команды для управления элементами и `hidden="until-found"`, позволяющий браузерному поиску раскрывать скрытый фрагмент страницы. У новых возможностей пока есть ограничения, но они помогают строить более простые и устойчивые интерфейсы.

- В [Firefox 154](https://developer.mozilla.org/en-US/docs/Mozilla/Firefox/Releases/154) появились сокращенная запись `text-box`, функции `sibling-index()` и `sibling-count()`. Последняя возможность одновременно [перешла в Baseline](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Values/sibling-index), поэтому ее поддержка становится достаточно широкой для практического применения.
- Mozilla рассказала о [планах добавить JPEG XL в Firefox](https://hacks.mozilla.org/2026/08/intent-to-ship-jpeg-xl/). Формат предлагает хорошее сжатие, HDR и широкую цветовую гамму; Chrome также готовит его поддержку.
- В [Chrome 153 Beta](https://developer.chrome.com/blog/chrome-153-beta?hl=en) тестируют новые возможности платформы, включая CSS-свойство `scroll-axis-lock`, которое ограничивает прокрутку выбранной осью.
- Официальное [расширение WordPress для браузера](https://wordpress.org/news/2026/08/browser-extension/) переносит частые действия из верхней панели администратора в интерфейс расширения.
- Статья об [аккордеоне, содержимое которого видит браузерный поиск](https://agustinbarrientos.com/writing/senior-eye/searchable-accordions/) показывает, как не спрятать полезный текст от функции «Найти на странице».
- Компонент [Form Saver](https://github.com/aarongustafson/form-saver) сохраняет значения формы в `localStorage`, восстанавливает их после неожиданного закрытия страницы и очищает после отправки. Поведение можно проверить в [живых примерах](https://aarongustafson.github.io/form-saver/demo/).
- Исследование показывает, как [AliExpress пытался распознавать устройства неслышимыми звуками](https://arstechnica.com/security/2026/08/aliexpress-caught-fingerprinting-visitors-after-sending-inaudible-sounds-to-browsers/). Защита Firefox нейтрализовала прием, а Chrome изначально не выдавал нужные данные.
- Авторы проекта 0.mk проверили 657 607 адресов и показали, [куда исчезают старые ссылки](https://0.mk/blog/link-rot). Страницы переезжают, домены закрываются, а накопленные знания постепенно становятся недоступными.

## 🎨 CSS и дизайн

### `flex-wrap: balance` равномерно распределяет элементы по строкам

Ahmad Shadeed разобрал [балансировку элементов с `flex-wrap: balance`](https://ishadeed.com/article/flex-wrap-balance/). Обычный перенос может оставить в последней строке одинокий элемент, даже если более равномерное распределение выглядело бы лучше. Новое значение пытается подобрать число элементов в каждой строке так, чтобы композиция оставалась аккуратной при разной ширине контейнера.

Вместе с ним предлагается `flex-line-count`, с помощью которого стили смогут учитывать количество получившихся строк. Пока обе возможности есть только в Chrome, поэтому в статье отдельно показаны интерактивные примеры и запасные решения.

### CSS готовится анимировать переходы между конкретными страницами

Предложение [CSS Navigation Matching](https://css-tricks.com/css-navigation-matching-early-days/) связывает страницы через правила `@location`, а переходы между ними описывает в `@navigation`. В перспективе это позволит оформлять разные анимации для движения вперед и назад или для конкретных маршрутов без JavaScript.

Сейчас это ранний черновик без реализации в браузерах. Но он показывает, как View Transitions могут превратиться из набора общих эффектов в полноценный способ описания навигации средствами CSS.

### От псевдообъема до настоящей 3D-сцены на CSS

Интерактивное руководство [«3D CSS: от Super Mario Bros. 3 до Mario 64»](https://www.carmenansio.com/articles/3d-css-guide/) начинает с плоской имитации глубины и постепенно переходит к трехмерным преобразованиям. Для этого достаточно разобраться с шестью свойствами и значениями, включая `perspective`, `preserve-3d` и `translateZ`.

- История [миграции с Sass на нативный CSS](https://chrissmith.xyz/blog/2026/the-process-of-migrating-from-sass-to-native-css/) объясняет, какие возможности препроцессора уже заменили переменные, вложенность и другие функции платформы.
- Будущий [селектор по префиксу класса](https://www.bram.us/2026/08/20/the-future-of-css-target-multiple-classes-with-the-class-prefix-selector/) может дать запись наподобие `.btn-*`, выбирающую все классы, начинающиеся с `btn-`.
- Генератор [`corner-shape` для сквирклов](https://a-dev.github.io/probes/corner-shape/) позволяет настроить форму ползунками, скопировать CSS и получить запасной вариант. У автора есть и [разбор техники с fallback](https://dev.to/a-dev/css-corner-shape-add-a-squircle-to-your-design-today-with-the-right-fallback-3ne6).
- [CSS-in-JS Arena](https://github.com/gajus/css-in-js-arena) сравнивает StyleX, Panda CSS и новый [Bamboo CSS](https://bamboocss.com/docs/overview/getting-started/) на одном приложении с React Router 8.
- [Dither](https://dither.neato.fun/) превращает изображения в настраиваемую векторную штриховку: можно выбрать градиент, один из девяти узоров, до восьми цветов и экспортировать результат в SVG или PNG.
- [Dither Image Online](https://ditherimage.online/) предлагает более простой способ добавить фотографии пиксельный ретро-эффект прямо в браузере.
- [Архив из более чем 11 000 изображений](https://pdimagearchive.org/) помогает находить вручную отобранные произведения, перешедшие в общественное достояние.

## 📦 JavaScript, Bun и фреймворки

### Bun 1.4 завершил большой переход с Zig на Rust

[Bun 1.4](https://bun.com/blog/bun-v1.4) стал результатом масштабной переработки рантайма. Команда отдельно описала [переезд с Zig на Rust](https://bun.com/blog/bun-in-rust), в котором для механической части использовала ИИ, а затем вручную доводила совместимость и производительность.

Релиз лучше работает с пакетами и инструментами из экосистем Node.js, а также с Next.js, Playwright, Vitest и Nuxt. Одновременно выросла пропускная способность и снизилось потребление процессора и памяти.

### Solid 2.0 RC перестраивает асинхронность вокруг реактивного графа

Публичный API уже заморожен перед финальной версией. Авторы библиотек могут начинать адаптацию, не ожидая новых крупных перестроений.

## ⚛️ React и Next.js

### Lovable перенесла 850 тысяч строк с Next.js на TanStack Start

В отчете Lovable объяснила, [как мигрировала с Next.js на TanStack Start](https://lovable.dev/blog/how-we-migrated-lovable-dev-away-from-nextjs). Проект насчитывал почти 400 маршрутов и больше 850 тысяч строк, поэтому одномоментный переход был бы слишком рискованным.

Команда поставила оба фреймворка за общим прокси, переносила маршруты постепенно и держала общий код в доступной обоим приложениям папке. Подход показывает, как раскладывать большую миграцию на небольшие проверяемые шаги.

### В Next.js закрыли две критические уязвимости удаленного выполнения кода

Разработчики опубликовали [августовское обновление безопасности Next.js](https://nextjs.org/blog/august-2026-security-release), исправляющее две критические RCE-уязвимости без аутентификации. Проекты на актуальной ветке следует обновить минимум до 16.3.3, а приложения на старой поддерживаемой ветке - до 15.5.24.

RCE означает, что злоумышленник может заставить сервер выполнить чужой код. Поэтому такое обновление нельзя откладывать до обычного цикла обновления зависимостей.

### React Canary учится откладывать отдельные компоненты до браузера

В Canary-канале появился API [`browser()`](https://react.dev/reference/react-dom/browser) для компонентов, которые невозможно отрисовать на сервере. Вызов `use(browser())` останавливает серверный рендер ветки, оставляет ближайший fallback от `Suspense`, а затем показывает компонент в браузере. Статус экспериментальных API объясняет [политика версионирования React](https://react.dev/community/versioning-policy#canary-channel).

Параллельные transitions [включили по умолчанию](https://github.com/react/react/pull/37290) в Canary-сборках, включая React Native. Механизм позволяет нескольким независимым обновлениям выполняться одновременно; [обсуждение реализации](https://github.com/react/react/pull/35392) помогает понять его устройство.

- Надежный [prefetch запросов с TanStack Router](https://tkdodo.eu/blog/reliable-query-prefetching-with-tanstack-router) выносит `queryOptions` в контекст маршрута, чтобы loader и компонент использовали одно определение.

### Как ИИ меняет фронтенд-разработку и обучение

Nolan Lawson размышляет об [«астероиде», который сталкивается с фронтендом](https://nolanlawson.com/2026/08/23/the-asteroid-currently-hitting-frontend-web-development/). Готовые ответы моделей обесценивают часть накопленных рецептов и меняют путь, по которому разработчики осваивают основы.
