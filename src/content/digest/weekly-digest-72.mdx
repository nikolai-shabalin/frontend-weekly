## 🧪 HTML и веб-платформа

### State of HTML 2026 показал, где разработчикам всё ещё трудно

В [результатах State of HTML 2026](https://2026.stateofhtml.com/en-US) разработчики рассказали, какими возможностями браузера уже пользуются. Среди способов добавить интерактивность лидируют раскрывающиеся блоки `<details>` с `<summary>` (72,5%) и диалоги `<dialog>` (67,8%). [Popover API](https://developer.mozilla.org/en-US/docs/Web/API/Popover_API), который помогает открывать подсказки и другие всплывающие элементы, используют около 40% участников опроса.

Больше всего сложностей со стилями доставляют списки `<select>` и поля для выбора даты. Распространение [настраиваемого `<select>`](https://2026.stateofhtml.com/en-US/usage/) сдерживает поддержка в браузерах. У `<datalist>`, который подсказывает варианты при вводе, [использование выросло с 30% до 44%, а доля положительных оценок снизилась](https://2026.stateofhtml.com/en-US/features/forms/) с 44% до 34%. Участники указали на ограничения в оформлении, проблемы доступности и ошибки в браузерах.

В списке пожеланий лидируют встроенные сортировка и фильтрация HTML-таблиц. В опросе также спросили, [какую долю кода участники генерируют с помощью ИИ](https://2026.stateofhtml.com/en-US/usage/#ai_generated_code_balance). В [итогах исследования](https://2026.stateofhtml.com/en-US/conclusion/) Килиан Валкхоф обращает внимание на срок ожидания новых возможностей, особенно на мобильных устройствах.

### Chrome 158 упрощает установку веб-приложений

В [Chrome 158](https://chromestatus.com/release-notes/158) появился элемент `<install>`. Он позволяет добавить на страницу кнопку, которая попросит браузер установить веб-приложение по его манифесту. CSS-псевдоклассы `:playing` и `:paused` помогают менять оформление плеера в зависимости от того, воспроизводится ли запись или стоит на паузе.

В этой версии Chrome [отключает XSLT по умолчанию](https://developer.chrome.com/docs/web-platform/deprecating-xslt) для сайтов, которые преобразуют XML прямо в браузере. В [обновлении DevTools](https://developer.chrome.com/blog/new-in-devtools-december-2026) можно принудительно включать состояния буферизации и остановки загрузки медиа. Панель Sources также умеет показывать исходные имена переменных, если их сохранил инструмент сборки.

### Chrome предлагает общий кеш для больших файлов

Команда Chrome представила [предложение Cross-Origin Storage API](https://developer.chrome.com/blog/introducing-cross-origin-storage). Идея в том, чтобы браузер мог скачать тяжёлый файл один раз и использовать ту же копию в разных веб-приложениях. Это пригодилось бы для шрифтов, моделей ИИ, модулей WebAssembly и игровых движков, которые часто загружаются с разных сайтов.

Файлы предлагается узнавать по криптографическому хешу, то есть по отпечатку содержимого. Если файл меняется, меняется и его отпечаток. API пока находится на стадии предложения.

### Safari появился на Apple HomeView

Команда WebKit рассказала, [как сайты работают в Safari на Apple HomeView](https://webkit.org/blog/18608/safari-on-apple-homeview/). У устройства квадратный семидюймовый экран и голосовое управление. Если сайт определяет устройство только по строке User-Agent, он может ошибочно принять HomeView за iPhone и выбрать неподходящую раскладку.

Лучше проверять реальную ширину и высоту окна. Подписи кнопок и полей помогают голосовому управлению однозначно определить, с каким элементом хочет взаимодействовать пользователь.

- Создатели Arc объявили, что [сворачивают работу браузера 22 декабря](https://arc.net). Крис Койер собрал [варианты для тех, кто ищет замену Arc](https://blog.master.dev/browsers-to-try-if-youre-being-forced-off-arc/), в том числе с боковой панелью и вертикальными вкладками.
- Патрик Броссе сделал [сравнение Chromium, Gecko и WebKit](https://patrickbrosset.com/lab/who-shipped-first). В нём можно посмотреть, какой движок первым добавил ту или иную возможность веб-платформы.

## 🎨 CSS и дизайн

### Диаграммы из обычных таблиц и списков

Кит Сёркел собрал [галерею диаграмм на HTML и CSS](https://k9l.io/htmlcharts). Среди примеров есть столбцы, линии, кольцевые диаграммы и тепловые карты. В основе каждого примера таблица или список с осмысленной разметкой. Если стили отключить, исходные числа и подписи всё равно можно будет прочитать.

### WebKit показал пространственный CSS

Страница может показать сцену прямо в комнате пользователя через JavaScript API. Эксперимент доступен за флагом в Safari на visionOS.

- Адам Аргайл показал [PropFLIP для плавной перестройки интерфейса](https://nerdy.dev/prop-flip). По [технике FLIP](https://css-tricks.com/animating-layouts-with-the-flip-technique/) элемент сначала оказывается на новом месте, а CSS временно сдвигает его обратно и плавно возвращает к новой позиции. В примере параметры движения задаются четырьмя свойствами, объявленными через `@property`.
- Вариативный [шрифт Allo](https://allo.joshpuckett.me/) позволяет менять толщину и округлость букв и автоматически подстраивает детали под размер текста. [Исходники шрифта](https://github.com/joshpuckett/allo) доступны на GitHub.
- В [коллекции Aura](https://auragradients.vercel.app/) больше 200 градиентов из слоёв с разными режимами смешивания. Их можно настроить и забрать как CSS, Tailwind, SVG или PNG. В [репозитории Aura](https://github.com/CristianOlivera1/Aura) доступны исходники редактора.

## 📦 JavaScript

В [jQuery 4.1 и 3.8](https://blog.jquery.com/2026/11/17/jquery-4-1-0-and-3-8-0-released-passing-the-torch/) команда обновила обе ветки библиотеки. В 4.1 можно узнать итоговый адрес запроса после перенаправления, а сериализация формы умеет включать значения пользовательских элементов, связанных с ней. Версия 3.8 получила часть исправлений и станет последним функциональным обновлением ветки 3.x. Дальше для неё запланированы критические исправления.

Тем, кто постепенно убирает библиотеку из проекта, пригодится [справочник по замене jQuery современным JavaScript](https://github.com/camsong/You-Dont-Need-jQuery). В [обновлении справочника до версии 3.0](https://github.com/camsong/You-Dont-Need-jQuery/releases/tag/v3.0) авторы убрали обходы ограничений Internet Explorer и добавили примеры с `replaceChildren()` и `structuredClone()`.

### Что на самом деле делает `resolve()` у промиса

Алистер Смит на примере [исправленной ошибки в работе с промисами](https://alistair.sh/thenables) разбирает разницу между вызовом `resolve()` и получением результата. Если передать в `resolve()` другой промис или объект с методом `then`, исходный промис будет ждать его результата. Вызов `resolve()` может уже произойти, а результат всё ещё оставаться неизвестным.

Ошибка затронула Safari и Bun, которые используют [движок JavaScriptCore](https://docs.webkit.org/Deep%20Dive/JSC/JavaScriptCore.html). Разбор помогает понять, почему у промиса есть состояния ожидания, успешного завершения и отклонения, а слово `resolved` описывает то, как определится его дальнейшая судьба.

- Габор Коош объяснил, [почему `JSON.stringify(error)` может вернуть пустой объект](https://blog.gaborkoos.com/posts/2026-11-12-Your-JS-Error-Is-Lying-to-You/). Стандартные поля ошибки обычно не перечисляются при сериализации. В статье показано, что происходит с сообщением, стеком вызовов и вложенной причиной ошибки при передаче между потоками и записи в лог.
- Разработчик компилятора из OCaml в JavaScript разобрал, [как функция с 13 тысячами локальных переменных переполнила стек V8](https://tarides.com/blog/2026-11-12-fixing-a-stack-overflow-shrank-js-of-ocaml-output-by-16). Исправление также сократило объём сгенерированного JavaScript на 16%.
- В [бета-версии XState 6](https://stately.ai/blog/2026-11-05-xstate-v6-beta) основной API готов к пробному использованию. XState помогает описать состояния интерфейса и допустимые переходы, например от ожидания запроса к получению данных или ошибке.
- В [SlickGrid 6.0](https://github.com/6pac/SlickGrid) убрали внешние зависимости и добавили закрепление строк и столбцов. [Демонстрация закрепления с четырёх сторон](https://6pac.github.io/SlickGrid/examples/example-pinning-columns-and-rows.html) показывает, какие данные остаются на экране при прокрутке большой таблицы. Другие сценарии собраны [на сайте SlickGrid](https://6pac.github.io/SlickGrid/).

## ⚛️ React

### React Flow 13 обновляет только нужные узлы

В [React Flow 13](https://xyflow.com/blog/react-flow-13-major-release) появились хуки `useNode` и `useEdge`, которые позволяют подписаться на данные конкретного узла или связи. Если пользователь перетаскивает один блок в большом редакторе схем, другим компонентам реже приходится обновляться. Для существующих проектов команда подготовила [руководство по переходу на версию 13](https://reactflow.dev/learn/troubleshooting/migrate-to-v13).

В ту же семью проектов [вошёл Vue Flow](https://xyflow.com/blog/vue-flow-joins-xyflow). У xyflow теперь есть редакторы графов для React, Vue и Svelte.

### Когда React 19.3 запускает анимацию перехода

Эстебан Трильо проверил [переходы представлений в React 19.3](https://devtrillo.com/writing/react-19-3-view-transitions/). Стабильный компонент `<ViewTransition>` может анимировать появление, исчезновение и перемещение частей интерфейса, например карточки при переходе из списка на страницу товара.

Чтобы анимировать обновление по нажатию кнопки, автор оборачивает вызов `setState` в `startTransition`. Одно и то же имя у `<ViewTransition>` на двух экранах помогает React сопоставить, например, миниатюру и её полноразмерную версию.

### Почему Next.js выпускает столько исправлений безопасности

Команда Next.js объяснила, [почему в 2026 году опубликовала 51 уведомление об уязвимостях](https://nextjs.org/blog/how-were-using-ai-to-make-nextjs-more-secure). ИИ помогает исследователям находить проблемы в уже работающем коде. Около 70% найденных в этом году уязвимостей затрагивали код, которому был как минимум год.

Кампания React2STEAL нацелилась на серверы, где остались старые уязвимости React и Next.js. В [памятке по проверке приложения после React2STEAL](https://www.chainguard.dev/unchained/react2steal-what-it-is-and-what-to-check) описано, какие версии и журналы проверить и когда нужно сменить ключи.

- Команда Next.js экспериментирует с [сервером Switchyard на Go](https://github.com/vercel/next.js/pull/101695). Сейчас прототип [работает перед `next start`](https://github.com/vercel/next.js/pull/102035) и пересылает запросы в Node.js. В будущем часть маршрутизации хотят перенести в Switchyard.
- Сергей Патракеев показал, [как отслеживать рост размера сборки Next.js](https://bra31k.dev/en/blog/bundle-size-regressions/). В его примере автоматическая проверка сравнивает объём JavaScript каждой страницы с заданным лимитом и замечает тяжёлые импорты до выпуска.
- В Remotion Studio теперь можно перетаскивать и обрезать элементы на шкале времени, сохраняя правки в исходниках. [Документация по интерактивным компонентам](https://www.remotion.dev/docs/studio/make-component-interactive) объясняет, как подключить к редактору свойства собственных React-компонентов.

### Что показали инциденты со сторонними скриптами

[Политика безопасности содержимого (CSP)](https://developer.mozilla.org/en-US/docs/Web/HTTP/Guides/CSP) позволяет ограничить, откуда браузер загружает скрипты и куда отправляет данные. [Проверка целостности ресурсов (SRI)](https://developer.mozilla.org/en-US/docs/Web/Security/Defenses/Subresource_Integrity) помогает убедиться, что скачанный файл совпадает с ожидаемой версией. Fathom отдельно описала, [как защищает и отслеживает изменения своего скрипта аналитики](https://usefathom.com/blog/how-we-secure-our-analytics-script).

- В [uBlock Origin 1.75.4](https://github.com/gorhill/uBlock/releases/tag/1.75.4) закрыли уязвимость в инструменте выбора элементов. Для пользователей расширения исправление доступно в этой и более новых версиях.
- После [перенаправления старых ссылок Bitly](https://ransomnews.com/burger-king-tweet-bitly-link-hijack-2026/) ссылки из давних публикаций стали вести на другие сайты. Для документов и инструкций, которыми пользуются годами, адрес на собственном домене даёт больше контроля над перенаправлениями.
- Лиран Таль объяснил, [как расставлять приоритеты при исправлении связанных уязвимостей](https://lirantal.com/blog/every-security-weakness-matters-vulnerability-chaining#prioritizing-findings-as-connected-paths). Ошибки стоит оценивать в контексте всего сервиса: две небольшие по отдельности проблемы могут иметь более серьёзные последствия, если связаны между собой.
- [Secretlint 14](https://github.com/secretlint/secretlint/releases/tag/v14.0.0) ищет в файлах токены, API-ключи и другие секреты. В [документации Secretlint](https://secretlint.github.io/) есть пример запуска проверки перед коммитом.

### npkill 1.0 находит кеши и старые сборки

[npkill 1.0](https://zaldih.com/en/post/npkill-1-0-0/) умеет находить `node_modules`, кеши и результаты сборки вроде `.next` и `.turbo`. Встроенные профили охватывают 20 экосистем. Утилита помогает найти самые крупные папки в старых проектах и выбрать те, которые можно восстановить повторной установкой или сборкой. В [документации npkill](https://npkill.js.org/) описано, как просматривать результаты поиска.

### Тестирование

- Команда Subito рассказала, [как перевела 10 144 теста с Jest на Vitest за три недели](https://dev.to/subito/we-migrated-10144-tests-from-jest-to-vitest-in-3-weeks-the-honest-ai-assisted-truth-527). В отчёте разобрали, какую часть изменений удалось автоматизировать и где понадобилась ручная проверка.
- [Flashwright](https://flashwright.dev/) сохраняет интерфейс и тестовый запускатель Playwright. В [разборе ускорения Flashwright](https://codebeast.io/blog/flashwright) авторы связывают выигрыш с повторным использованием браузерного контекста для каждого рабочего процесса и изменениями в ожидании анимаций. В их тестах ускорение составило от двух до четырёх раз.
- [BugShot](https://bug-shot.com/) добавляет в Chromium боковую панель для оформления отчётов об ошибках. К отчёту можно приложить снимок экрана с пометками и журнал браузера, а затем отправить его в трекер задач.

### Форматирование, Git и выпуск пакетов

- [Prettier 3.10](https://prettier.io/blog/2026/11/11/3.10.0) разбирает новые конструкции JavaScript и Flow. Для JS и TS появился подключаемый [парсер Yuku](https://yuku.fyi/), написанный на Zig.
- [semantic-release 26](https://github.com/semantic-release/semantic-release/releases/tag/v26.0.0) требует Node.js 26.13 или новее и поставляется с npm 12. [Документация semantic-release](https://semantic-release.org/) показывает, как автоматически определять номер версии и публиковать пакет по истории изменений.
- [hk](https://hk.jdx.dev/) помогает один раз описать линтеры и форматеры, а затем запускать те же проверки перед коммитом и в CI.
- [DiffsHub](https://diffshub.com/) открывает изменения из публичных коммитов и пул-реквестов GitHub в отдельной панели сравнения. Для перехода достаточно заменить домен в адресе страницы.
- [PR Comment Inbox](https://github.com/humanwhocodes/pr-comment-inbox) собирает обсуждения из ревью GitHub в одном интерфейсе. При выборе комментария можно посмотреть соответствующее изменение и ответить в той же панели.
- На [Git Skills](https://www.git-skills.dev/) есть короткие уроки и тесты для практики Git, от привычных команд до работы с историей.

### Файлы, документация и другие находки

- [File Viewer](https://github.com/flyfish-dev/file-viewer) показывает документы Office, PDF, чертежи, архивы и письма в режиме чтения. В [демонстрациях File Viewer](https://file-viewer.app/) можно проверить доступные форматы и посмотреть интеграции с React, Vue и Svelte.
- В [Mediabunny 1.66](https://github.com/Vanilagy/mediabunny/releases/tag/v1.66.0) исправили обработку медиафайлов в браузере и Node.js. Часть проблем авторы обнаружили во время [проверки кода с помощью ИИ](https://github.com/Vanilagy/mediabunny/pull/636).
- [Fontkit 3.0](https://github.com/foliojs/fontkit) работает как ESM-пакет в Node.js и браузере. Базовый экспорт `core` позволяет подключить только нужные парсеры форматов шрифтов.
- [D2](https://d2lang.com/) превращает текстовое описание в диаграмму. Схему можно хранить рядом с кодом и проверять изменения в ней через Git.
- [Oxynote](https://oxynote.io/) объединяет инженерную документацию, схемы, показатели и журналы в одном редакторе. У изменений есть история сравнения версий.
- [Starboard](https://github.com/palamim/starboard) размещает терминал рядом с Dock в macOS. Панель остаётся доступной при переключении рабочих столов.
- [Unclaimed](https://github.com/iannuttall/unclaimed) проверяет из терминала, свободно ли доменное имя. Поиск можно ограничить выбранными доменными зонами.
- [TomSEOTools](https://tomseotools.com/) объединяет браузерные инструменты для работы с изображениями, PDF и анализа текста.
- [MDN Traffic](https://ready-unit-fowl.codepen.app/) визуализирует посещения MDN по странам. Одни и те же данные можно посмотреть на столбчатом графике, круговой или многоуровневой кольцевой диаграмме.
- В [Link Tapes](https://linktapes.com/) можно вместе с друзьями собирать музыкальные подборки из ссылок и смотреть открытые подборки других пользователей.
